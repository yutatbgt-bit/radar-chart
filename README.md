# 店舗売上KPI レーダーチャート＆カンバンダッシュボード (radar-chart)

ブラウザ上で動作する、高速・高セキュリティ・リッチデザインの店舗売上KPI可視化ダッシュボードです。  
外部ライブラリ（Chart.js、D3.js、jQuery等）やサーバーサイド処理に一切依存せず、純粋な HTML5 / CSS3 / Vanilla JavaScript のみで構築されています。

---

## 🚀 主な機能・特徴

- **4列カンバンビュー（全24店舗）**
  - 店舗を「大型店」「中型店A」「中型店B」「駅中・コンビニ」の4カテゴリに分類し、視覚的に一覧比較可能。
- **高精度 Pure SVG レーダーチャート**
  - 外部描画ライブラリ不使用。DOM/SVG APIによる軽量かつ鮮明なベクター描画。
  - **端100%基準スケール**: 100%達成ラインを明確に視覚化。
  - **全自動三角関数オフセット**: チャートの頂点数（5項目、6項目、7項目〜）に応じて、実績値ラベル（`xx.xx%`）や軸タイトルが重ならないよう数学的に最適な位置へ自動逃がし配置。
- **詳細モーダルダイアログ**
  - 店舗カードをクリックすることで、大型レーダーチャートと詳細数値を拡大表示。
- **ダークモード / ライトモード対応**
  - 高級感ある「ラグジュアリー・ダークモード」と、高コントラストで視認性の高い「エレガント・ライトモード」をワンクリックで切り替え可能（`localStorage` に設定を永続化）。
- **ドラッグ＆ドロップ CSV アップロード & クリア機能**
  - 日常業務のCSVデータを画面上にドラッグ＆ドロップ（またはファイル選択）するだけで瞬時に全店舗のチャートを生成。
  - 初期状態はクリーン起動（数値未設定 `-` 表示）。「クリア」ボタンで即座にリセット可能。
- **ゼロトラスト・セキュリティ設計**
  - `innerHTML`、`outerHTML`、`document.write`、`eval`、`new Function` などの危険APIを完全排除。
  - データはブラウザ内（メモリ上）でのみ処理され、外部サーバーへの通信・データ送信は一切行われません。

## 📊 表示指標（デフォルト5項目）

1. **売上高比較日比**（前年同曜日比の売上高達成率）
2. **客数比較日比**（前年同曜日比の来店客数比）
3. **打数比較日比**（前年同曜日比のレジ打数比）
4. **客単価比較日比**（前年同曜日比の客単価比）
5. **一品単価比較日比**（前年同曜日比の一品単価比）

※本システムは可変長データ駆動型で設計されており、6項目以上の項目追加・変更にも完全対応しています。

## 💻 動作環境・利用方法

### 動作環境
- モダンブラウザ（Google Chrome, Microsoft Edge, Mozilla Firefox, Safari 等の最新版）
- Webサーバー不要（ローカルPC上で `radar chart.html` を直接ブラウザで開くだけで即座に動作）

### 利用手順
1. 本リポジトリをクローンまたはZIPダウンロードします。
   ```bash
   git clone https://github.com/yutatbgt-bit/radar-chart.git
   ```
2. フォルダ内の `radar chart.html` をダブルクリック（またはブラウザへドラッグ＆ドロップ）して開きます。
3. 画面右上の「CSVファイルをドロップ または 選択」ボタンから、売上データCSVを読み込みます。
4. 全24店舗のレーダーチャートと指標テーブルが即座に展開されます。
5. 各店舗カードをクリックすると、詳細拡大モーダルが表示されます。

## ⚙️ カスタマイズ（指標の追加・変更方法）

指標の項目数（5項目から6項目・7項目などへの拡張）や店舗の変更は、`js/config.js` を編集するだけで反映されます。

```javascript
// js/config.js の metrics 配列に新しい指標を追加
metrics: [
  // ...既存の指標...
  {
    id: "grossMarginRatio",
    key: "粗利率比較日比",
    label: "粗利率比較日比",
    shortLabel: "粗利率",
    colIndex: 16,        // CSV内の該当列番号
    min: 0,
    max: 100,
    benchmark: 100.0,
    unit: "%",
    description: "前年同曜日比の粗利率達成率"
  }
]
```
`chart.js` の描画エンジンは自動的に N角形グリッドおよびオフセット角度を再計算するため、コードのロジック修正なしで新しい多角形チャートが描画されます。

## 🔒 セキュリティとプライバシー

- **外部通信ゼロ**: CDN等の外部スクリプトの読み込みを行わず、完全オフライン環境（イントラネット、社内LAN、機密環境）でも動作します。
- **データ非保持**: CSVデータはブラウザのメモリ内でのみ一時展開され、Cookieやサーバーに保存・送信されることはありません。
- **DOM XSS対策**: 全てのテキスト描画に `textContent` および `createElementNS` を使用し、スクリプトインジェクションを物理的に防御しています。
